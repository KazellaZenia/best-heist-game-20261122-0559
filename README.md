IRONVEIL — The Meridian Vault Heist: a top-down 2D stealth game. One thief, one night, five rooms on a single floor. Sneak past four named guards (ROOK, VERA, MOSS, IRIS) with raycast vision cones and patrol → suspicious → chase → search AI, dodge three sweeping CCTV cameras and cycling laser beams, and lift $40,000 of named loot — the Meridian Diamond, the Aurum Death Mask, the Sapphire Tiara, the Jade Falcon, the Cipher Drive and the Gilded Ledger — then slip out the Lobby exit before the alarm meter hits 100. Marble floors are loud, carpet is quiet, Shift sneaks; the GHOST / SHADOW / DETECTED rating, score, combo chain and best score are all tracked on screen. Keyboard + mouse, no network, static files only, all art drawn procedurally in code.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — WASD / arrows move, Shift sneaks, click to walk, Space pauses, M mutes, Enter starts. Or run the entry program directly: `MAKEFUN_OUTPUT_DIR=out node main.ts`.
